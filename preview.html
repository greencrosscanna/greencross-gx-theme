Bug report — one shared form, replacing four

Built entirely by gx-bugreport.js; no app writes this markup. It replaces three near-identical local copies (21 .bug-* CSS rules each) plus Price Cards' window.prompt(), and gives SPIFF and Crew a reporter they never had. Open it and expand “What gets sent with this” — every report carries the reporter's state (route, viewport, browser, last console error, plus whatever the app adds). That snapshot is what this suite has instead of an attached screenshot: a browser POST to GX Core does not work, so an image has no transport, but text rides the same GET the report already rides.

Submitting here is a no-op — the preview passes a stub transport, so nothing is filed.

Version history — one popup, replacing four (and filling three gaps)

Built entirely by gx-changelog.js, reading GX Core's version_history route. Leaderboard, Inventory, Sales and the Command Center each had their own modal; Price Cards, SPIFF and Crew had none, so their Version row was a dead label. Clicking Version in the user chip above opens this — no app wires it, though an app that wants its own popup keeps it by calling preventDefault() on the event.

The footer toggles between the consolidated release notes and the full deploy log, and only appears when consolidation actually dropped something. Versions render in the suite format vMAJOR.BBB — the fixed 3-digit build is what makes “is this newer than what I've seen” answer the same way everywhere.
